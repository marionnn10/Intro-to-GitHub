# Intro-to-GitHub

This repository was created as part of an introductory activity about Git and GitHub.

## Purpose

The purpose of this repository is to practice the basic operations of Git and GitHub, including creating repositories, uploading files, cloning repositories, committing changes, and pushing changes to GitHub.

## Files

This repository contains sample files used to demonstrate basic Git and GitHub operations.
